# Kunanib'al - Plataforma SaaS para Clínicas Médicas

> **Kunanib'al** es una plataforma SaaS multi-tenant diseñada específicamente para la gestión eficiente de clínicas médicas en Guatemala.

## Visión General

El objetivo principal de Kunanib'al es simplificar la administración de citas, expedientes clínicos y operaciones diarias de una clínica. Está orientado a clínicas pequeñas y medianas que buscan digitalizar y optimizar sus procesos, dejando atrás herramientas genéricas como Excel, WhatsApp manual y agendas de papel.

## Problemas que Resolvemos

1. **Conflictos de Agenda:** Eliminamos solapamientos de horarios mediante validaciones estrictas de disponibilidad por doctor.
2. **Citas Perdidas (No-Shows):** Reducimos el ausentismo automatizando los recordatorios de citas vía WhatsApp.
3. **Historial Fragmentado:** Garantizamos la continuidad médica centralizando el expediente clínico de cada paciente en un solo lugar seguro.
4. **Complejidad Administrativa:** Ofrecemos una interfaz moderna, rápida e intuitiva para que recepcionistas y médicos puedan operar con una capacitación mínima.

## Modelo de Negocio SaaS

Kunanib'al opera bajo un modelo de suscripción mensual (SaaS), permitiendo a múltiples clínicas operar de forma simultánea, segura y completamente aislada mediante una arquitectura Multi-Tenant.

Planes escalables proyectados:
- **Plan Básico:** Ideal para consultorios pequeños.
- **Plan Medio:** Para clínicas en crecimiento.
- **Plan Alto:** Para centros médicos establecidos.

## Funcionalidades Principales

- **Gestión de Agenda:** Calendario interactivo con código de colores por doctor para crear, reprogramar y cancelar citas.
- **Expediente Clínico Digital:** Registro detallado de la historia clínica (Notas Clínicas).
- **Recetas Médicas:** Generación de recetas en formato PDF listas para imprimir o enviar.
- **Recordatorios por WhatsApp:** Notificaciones automáticas para confirmar asistencia.
- **Control de Roles:** Accesos granulares para Recepcionistas, Doctores, Administradores de Clínica y SysAdmin.
- **Identidad Visual (White-Label parcial):** Cada clínica configura su logo y colores corporativos, fortaleciendo su marca.

## Estado del Proyecto
